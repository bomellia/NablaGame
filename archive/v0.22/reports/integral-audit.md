# 積分パターン監査 — v0.8

## 実行条件
- seed 27、COM同士6試合、各試合80ターン上限（全試合完走）、計349ターン
- 各ターンの両者全基底に微分と積分を直接適用
- x、x²、e^x、sin x、cos x の関数カードとの積・商（両方向）を生成し、正規化後の式にも微積分を適用
- 重すぎる派生式はスキップ。計算はオフラインJavaScript上で実施（プレイ中にLLMへ送信しない）

## 結果

| 指標 | 件数 |
|---|---:|
| 完走 | 6/6 |
| 対戦ターン数 | 349 |
| 微分成功 / 失敗 | 33,776 / 0 |
| 積分成功 / 不成立 | 23,537 / 10,239 |

不成立には未対応のパターンと非初等積分の可能性があるパターンの双方が含まれます。
「初等積分不可」という証明ではありません。

## 見つけた式から追加した処理
- `1/√x = x^(-1/2)` と冪乗公式
- `exp(-x) exp(x)=1`、`(x²)^(-1)=x^(-2)` などの正規化
- `exp(ax)sin(bx)`、`exp(ax)cos(bx)`
- `sin^m(ax)cos^n(ax)` （置換積分・有限フーリエ展開）
- `exp(ax)/x^n`、`sin(ax)/x^n`、`cos(ax)/x^n` を Ei/Si/Ci へ帰着
- `1/(a+b exp(kx))`、一部の三角関数の商
- 一次式の冪・一部の二次式の逆平方根や逆3/2乗

## 現時点で対応しない形
- `exp(x) sec(x)`、`exp(x) csc(x)`
- `x sec(x)`、`x csc(x)` など
- 非線形な合成関数や高次の有理関数

計算できないときに未評価の積分記号を盤面へ残すことはせず、操作を拒否します。

## 再現方法

```bash
node integral-audit.mjs 27 6 80
```

`audit-results.json` に未対応式のAST、式の表示、発生回数、理由を保存します。
